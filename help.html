Setup guides for Audex's optional features. If you're stuck on something not covered here, get in touch — or use the "We listen to you" feedback option inside the app.

Topics

  1. Generate your own Google Cloud Text-to-Speech API key

Generate your own Google Cloud Text-to-Speech API key

Audex reads your books aloud using a free, fully offline voice by default — no setup needed. If you'd like a higher-quality neural voice instead, you can turn on Cloud voices in Settings and supply your own Google Cloud API key. It's billed to your own Google Cloud account, not shared with any other Audex user, and Google Cloud's Text-to-Speech API includes a free monthly quota that's generous for typical listening.

  1. Create a Google Cloud project

    If you don't already have one, create a new project — this is just a free container for the API you're about to enable. Any name works.

    Create a project in Google Cloud Console
  2. Enable billing on the project

    Google Cloud requires a billing account attached before it will issue API keys for most APIs, even ones with a free tier — you won't be charged unless you go past the free monthly quota, and you can set a spending cap. New accounts also typically get Google Cloud's own free trial credit.

    Set up billing
  3. Enable the Text-to-Speech API

    With your project selected, enable the Cloud Text-to-Speech API for it. This is the same link Audex's own "Get an API key" button opens.

    Enable the Text-to-Speech API
  4. Create an API key

    Go to APIs & Services → Credentials, click Create Credentials, and choose API key. Google Cloud will generate the key immediately — copy it somewhere safe.

    Open Credentials
  5. Recommended: restrict the key to Text-to-Speech only

    On the same Credentials page, click the key you just created, and under API restrictions choose Restrict key and select only Cloud Text-to-Speech API. This means the key can't be used for anything else if it were ever leaked.

  6. Paste it into Audex

    In Audex, go to Settings → Books & voices → Cloud voices, turn on Use your own Google Cloud API key, and paste the key into the field. It's stored encrypted, only on your device.

Note: Audex tracks your usage locally and lets you set a safety cap per voice tier in Settings, so you won't be surprised by billing — but the authoritative usage/billing numbers always live in your own Google Cloud Console, not in the app.
